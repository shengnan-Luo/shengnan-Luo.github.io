# Shengnan Luo — Academic Website

This repository contains the source code for [Shengnan Luo's academic website](https://shengnan-luo.github.io/).

Shengnan Luo is a master's student in [Shengli Li's lab](https://lishenglilab.github.io/) at Shanghai Jiao Tong University School of Medicine. Research interests include biomedical applications of large language models and integrative multi-omics.

## Website Content

- About and research interests
- Publications
- Honors and awards
- Curriculum vitae
- English and Chinese language support

## Local Development

Node.js 22 or later is required.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

Run a production build with:

```bash
npm run build
```

## Deployment

The website is statically exported and deployed to GitHub Pages through GitHub Actions whenever changes are pushed to the `main` branch.

## Acknowledgements

This website is built with [PRISM](https://github.com/xyjoey/PRISM), a configurable academic portfolio template based on Next.js, Tailwind CSS, and TypeScript.
